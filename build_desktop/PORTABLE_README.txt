SFSC - Steel Fan Support Calc
Portable Windows package

How to run
1. Extract this ZIP to any folder.
2. Double-click SFSC.exe.
3. Wait a few seconds on the first launch while Windows extracts the portable app.

Notes
- No installer is required.
- The app does not create a Start Menu entry.
- The app does not install files into LocalAppData.
- The app opens in its own desktop window.
- During execution, Windows may create temporary PyInstaller files in the system temp folder. They are not a permanent installation.
- The app starts a local backend on 127.0.0.1, normally from port 8502. If that port is busy, the launcher uses the next free port.
- This software supports only the documented engineering scope and weight policy. Results marked REQUIRES_SPECIALIST require review by a qualified structural engineer.

If Windows SmartScreen appears, choose "More info" and then "Run anyway" only if you downloaded this file from the official project Release.
If antivirus software reports a possible threat, verify the release source and SHA-256 hash before running the executable. Portable PyInstaller apps can trigger false positives because they unpack runtime files to a temporary folder.
